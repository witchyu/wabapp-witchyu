# Witchyu — Mobile Booking App

เว็บแอปจองคิวดูดวง (Mobile-first) — **ตอนนี้อยู่ PHASE 1: Mobile UI (ใช้ข้อมูลจำลอง)**

## รัน
```bash
cd frontend
npm install
npm run dev      # เปิด http://localhost:5173 (Codespaces: เปิดจากแท็บ PORTS พอร์ต 5173)
npm run build    # ตรวจ TypeScript + build
```

## หน้าที่มีใน Phase 1
| Route | หน้า |
|---|---|
| `/` | Home |
| `/services` | บริการทั้งหมด 8 เซ็ตคำถามตามระบบเดิม (+ ดูรายละเอียดคำถามในเซ็ต) |
| `/booking` | จองคิว 5 ขั้นตอน (ข้อมูล → บริการ → วันเวลา → หมายเหตุ → สรุป) |
| `/payment/:id` | ชำระเงิน **จำลอง** |
| `/success/:id` | จองสำเร็จ |
| `/bookings`, `/bookings/:id` | การจอง / รายละเอียด |
| `/chat` | Placeholder (ทำจริง Phase 5) |
| `/profile` | โปรไฟล์ |

## ขั้น "เลือกบริการ"
- เรียงตามเซ็ตคำถามเดิม: เจาะจง (+พิมพ์จำนวนเอง) → โทร → เป็นเรื่องๆ → 2 ทางเลือก → ความรัก 59 → ความรัก 49 → การงาน → การเรียน
- ปุ่ม "เลือกหลายรายการ" / "ยกเลิก" อยู่มุมขวาบนของหน้า (ขั้นที่ 2)
- เปิดโหมดแล้ว 3 เซ็ตแรกถูกบล็อกพร้อมข้อความ "ไม่สามารถเลือกหลายรายการได้" ส่วนที่เหลือเลือกได้หลายรายการจนกว่าจะกดยกเลิก (ยกเลิก = ล้างที่เลือกทั้งหมด)
- ราคาของ "อื่นๆ" (2 ทางเลือก) ใช้ 49 บาทตามระบบเดิม

## ข้อจำกัดของ Phase 1 (ตั้งใจ)
- ข้อมูลบริการ/การจอง/สถานะเวลาเป็น Mock (`src/data`, `src/services/mockBookings.ts`, `src/utils/slots.ts`) — จะย้ายไป Database ใน Phase 3-4
- ปุ่มที่ยังเป็น Placeholder: โทร, แชต, แจ้งเตือน, ความเป็นส่วนตัว, ติดต่อเรา, ออกจากระบบ (มีป้าย "เร็ว ๆ นี้" หรือแจ้งใน toast)
- การจองใหม่ยังไม่ถูกเก็บถาวร (รีเฟรชแล้วหาย) — Phase 2 จะเพิ่ม LocalStorage
- ปุ่ม "ฉันชำระเงินแล้ว" เป็นการจำลอง ไม่ได้ยืนยันเงินเข้าจริง
- เก็บ LocalStorage เฉพาะ "ข้อมูลผู้จอง" เมื่อติ๊กบันทึกไว้
- ไม่มีแบบทดสอบ/เกม/Quiz ตามที่กำหนด

โปรเจกต์เว็บเดิม (`public/`, `server.js`) ไม่ได้ถูกแก้ไขหรือลบ — โฟลเดอร์ใหม่คือ `frontend/`
